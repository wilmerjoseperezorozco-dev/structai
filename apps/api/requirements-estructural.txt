# ── Motor Estructural / Infracortex (IFC + PINN) — instalación OPCIONAL ──
# Se instala aparte de requirements.txt, solo cuando se necesita.
# Corresponde exactamente a lo que main.py importa dentro de
# `if os.getenv("ENABLE_ESTRUCTURAL", "false").lower() == "true":` — con
# esa variable en false (default en producción hoy, por límite de RAM de
# la instancia — ver el comentario junto a esa línea en main.py), estos
# paquetes nunca se importan aunque estén instalados; si no están
# instalados y alguien activa ENABLE_ESTRUCTURAL=true, main.py lo captura
# con ImportError y deja ESTRUCTURAL_AVAILABLE=False sin tumbar el resto
# de la API.
#
# Build CPU-only de torch (--extra-index-url abajo) — la instalación
# GPU/CUDA por defecto arrastra ~5-6GB de paquetes nvidia-* totalmente
# innecesarios: la red del motor es un MLP pequeño que corre bien en CPU,
# y las instancias de DigitalOcean App Platform no tienen GPU.
#
# torchvision NO está aquí a propósito: confirmado que ningún código del
# repo lo importa (ni motor-estructural ni ningún otro), incluirlo sería
# repetir el mismo desperdicio que se está corrigiendo.
#
# Instalar junto al core:
#   pip install -r requirements.txt -r requirements-estructural.txt
#
# Ver Dockerfile (ARG INSTALL_ESTRUCTURAL) para habilitarlo en el build
# de producción de DigitalOcean.
