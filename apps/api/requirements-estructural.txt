# ── Motor Estructural / Infracortex (IFC) — instalación OPCIONAL ──────────
# Se instala aparte de requirements.txt, solo cuando se necesita.
# Corresponde exactamente a lo que main.py importa dentro de
# `if os.getenv("ENABLE_ESTRUCTURAL", "false").lower() == "true":` — con
# esa variable en false (default en producción hoy), estos paquetes nunca
# se importan aunque estén instalados; si no están instalados y alguien
# activa ENABLE_ESTRUCTURAL=true, main.py lo captura con ImportError y
# deja ESTRUCTURAL_AVAILABLE=False sin tumbar el resto de la API.
#
# torch salió de aquí el 2026-08-26: motor-estructural traía una
# MultidisciplinaryPINN (red PyTorch) que se instanciaba en cada análisis
# real pero nunca se usaba para nada -- el veredicto siempre salió 100% de
# fórmulas clásicas (load_engine.py, sin torch). Se eliminó ese código
# muerto (ver infracortex_core.py), así que este archivo ya no necesita
# su propio pin de torch.
#
# Corrección real sobre el motivo original de este archivo (el comentario
# viejo decía "requirements.txt ya no trae torch" -- eso era impreciso):
# sentence-transformers (en requirements.txt, siempre instalado, lo usa el
# RAG) YA exige torch como dependencia dura -- confirmado con
# `pip show sentence-transformers` (Requires: ... torch ...). El pin
# CPU-only que vivía aquí (torch==2.13.0+cpu, con su propio
# --extra-index-url) era además un riesgo real de conflicto de versión
# contra el torch que requirements.txt ya resuelve por su cuenta -- pip
# tenía que reconciliar dos especificaciones de torch en dos pasadas de
# instalación separadas. Motor-estructural, sin la PINN, no vuelve a tocar
# torch para nada.
#
# Instalar junto al core:
#   pip install -r requirements.txt -r requirements-estructural.txt
#
